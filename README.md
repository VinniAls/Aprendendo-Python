# Sabor Express

Aplicativo de terminal para gerenciar restaurantes. Este projeto está no início do desenvolvimento.

## Funcionalidades

- Cadastrar restaurantes com nome e categoria
- Listar restaurantes e seus status
- Ativar ou desativar restaurantes

## Como executar

É necessário ter o Python 3 instalado.

```bash
python app.py
```

No menu, escolha uma opção digitando o número correspondente.

> Os dados cadastrados são mantidos apenas enquanto o programa está em execução.
